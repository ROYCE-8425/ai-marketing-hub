## 1. Muc tieu

Them mot workspace moi de he thong co the doc du lieu hien tai cua website va dua ra de xuat hanh dong co uu tien.

Feature nay khong phai la "AI tu doan". No phai dung du lieu that trong he thong, tinh ra cac tin hieu chac chan truoc, sau do moi de AI tong hop va viet khuyen nghi bang tieng Viet.

Ket qua mong muon:
- Gom du lieu SEO/marketing hien co thanh 1 phien phan tich thong nhat
- Phat hien van de va co hoi tang truong dua tren du lieu that
- Dua ra action plan 7 ngay va 30 ngay
- Van hoat dong duoc ngay ca khi khong co AI key, theo kieu deterministic insights

## 2. Van de hien tai

### 2.1 Du lieu dang bi phan tan
Du an da co nhieu nguon du lieu co gia tri:
- GSC keywords / impressions / clicks
- GA4 overview
- SERP live
- Rank tracker
- Technical SEO
- Core Web Vitals
- Broken links
- Schema validation
- Usage history cua he thong

Nhung hien tai cac nguon nay dang nam o nhieu module rieng, user phai tu ghep bang tay de hieu website dang yeu o dau.

### 2.2 AI hien tai chua dong vai tro "co van"
He thong da co AI cho:
- viet noi dung
- phan tich keyword
- polish / spin
- GEO

Nhung chua co 1 lop tong hop de tra loi cau hoi thuc te:
- website nay dang mat traffic o dau
- trang nao can uu tien sua
- tu khoa nao co quick win
- van de ky thuat nao dang chan tang truong
- nen lam gi trong 7 ngay toi

### 2.3 Khong nen cho AI doc raw data truc tiep
Neu dua AI mot dong raw dump lon, ket qua se:
- kho defend
- de ao tuong chinh xac
- de bo sot signal quan trong
- ton token vo ich

Can co lop backend tinh signal chac chan truoc, roi moi dua snapshot da chuan hoa cho AI.

## 3. Nguyen tac thiet ke

### 3.1 Tach 3 lop du lieu
Feature nay phai tach ro:

1. Measured facts
- du lieu API that
- du lieu HTML / HTTP / DB that
- rank / click / impression / sessions / issues that

2. Rule-based insights
- quick wins
- ranking drops
- low CTR / high impression
- technical blockers
- content gaps

3. AI summary
- tom tat
- uu tien
- action plan
- cach dien giai bang ngon ngu de hieu

### 3.2 AI khong duoc la tang tinh toan dau tien
Backend phai tinh signal truoc.
AI chi nen:
- tong hop
- giai thich
- sap xep uu tien
- viet de xuat hanh dong

### 3.3 Graceful degradation
Neu thieu `GROQ_API_KEY`, feature van phai hoat dong voi:
- summary generated by templates
- deterministic issues
- quick wins
- action checklist co ban

Khong duoc crash hoac tro thanh mock UI.

## 6. Tin hieu backend can tinh truoc

### 6.1 Search / Traffic signals
- impression cao nhung CTR thap
- keyword dang o vi tri 4-15 => quick win
- keyword giam hang trong 7-30 ngay
- page co nhieu view nhung engagement thap
- organic opportunities theo keyword cluster

### 6.2 Content signals
- page traffic cao nhung content mong
- page chua co FAQ / list / table / answer blocks
- topical gaps tu competitor / SERP
- intent mismatch co kha nang xay ra

### 6.3 Technical signals
- CWV yeu
- broken links
- schema thieu / invalid
- technical issues critical
- heading / meta / indexability gaps

### 6.4 Product usage signals
- user dung module nao nhieu
- module nao fail nhieu
- endpoint nao cham / loi nhieu

Khong dua product usage vao SEO score. No chi de cai thien san pham va uu tien support.

## 7. API de xuat

### 7.1 Main endpoint
`POST /api/advisor/analyze`

Request goi y:

```json
{
  "site_url": "https://example.com",
  "target_keyword": "dich vu seo",
  "days": 30,
  "include_gsc": true,
  "include_ga4": true,
  "include_serp": true,
  "include_rank_tracking": true,
  "include_technical": true,
  "include_cwv": true,
  "include_schema": true,
  "include_usage_history": true
}
```

### 7.2 Response shape goi y

```json
{
  "site_url": "https://example.com",
  "analyzed_at": "2026-06-02T10:00:00",
  "confidence": "medium",
  "summary": "Website dang co co hoi tang CTR o nhom tu khoa co impression cao...",
  "top_issues": [],
  "quick_wins": [],
  "technical_blockers": [],
  "content_opportunities": [],
  "action_plan_7d": [],
  "action_plan_30d": [],
  "data_snapshot": {},
  "source_status": {
    "gsc": "ok",
    "ga4": "ok",
    "serp": "partial",
    "technical": "ok",
    "usage_history": "ok"
  }
}
```
